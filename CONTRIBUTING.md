# Contributing

Thanks for taking the time. Everything in these repos is meant to be copied, so the most useful contributions are the ones that make a recipe, skill or demo easier to use for the next person.

## Good ways to help

- **Something broken or confusing:** open an issue with the page or file, what you expected, and what happened instead. A screenshot or the prompt you used helps most.
- **A small fix:** typos, a clearer sentence, an accessibility problem, a bug in a demo. Open a pull request straight away.
- **A bigger idea:** a new recipe, skill or pattern. Open an issue first so we can agree on the shape before you spend time on it.

## What I check before merging

- **Accessible:** keyboard works, focus is visible, contrast passes WCAG 2.2 AA, and motion respects reduced motion settings.
- **One file stays one file:** the demos have no build step and no libraries beyond what they already load.
- **Honest:** no invented results or numbers, and anything written by AI is labelled and checked.
- **Private stays private:** no email addresses, phone numbers, keys or personal details in code, screenshots, GIFs or PDFs. Read every frame of a recording before you add it.

## Style

Plain language, short sentences, written for the person using it. Match the tone of the file you're editing.

By contributing, you agree your contribution is shared under the same license as the repo (MIT for the code and kits).
