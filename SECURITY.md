# Security

These repos are small demos, kits and write ups, but if you find something that could hurt people who use them, please tell me privately first.

**How to report:** use "Report a vulnerability" on the repo's Security tab, or email hello@miguelclavel.com. Please don't open a public issue for it.

**Useful to include:** the repo and file, what someone could do with it, and how to reproduce it.

**What to expect:** a reply within a few days, a fix as soon as I can make one, and credit if you'd like it.

Things worth reporting: a demo that runs untrusted input as code, a skill or script that could leak files or secrets, or anything private that slipped into a file, image or recording.
